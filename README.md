# Fauna Atlas

Aplikasi Flutter untuk latihan kuis praktikum: login NIM, katalog satwa yang
dapat dicari dan difilter, serta halaman detail responsif untuk ponsel dan
desktop.

## Kredensial login

Atur `username` menjadi NIM dan `password` menjadi nama program studi pada
`lib/config/login_credentials.dart` sebelum menjalankan aplikasi.

## Menjalankan aplikasi

```sh
flutter pub get
flutter run
```
